# Full-Stack MERN User Management System

A full-stack web application built using MongoDB, Express.js, React.js, and Node.js.

## Features
- View users
- Add new users
- Update user details
- Delete users

## Technologies
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Axios

## Project Structure
- `client/` — React frontend
- `server/` — Express backend
- `.gitignore` — Files excluded from Git

## Environment Variables

Configure these variables in your deployment dashboards. Never commit real credentials.

### Backend (Render)
- `MONGO_URL` — MongoDB Atlas connection string
- `CLIENT_URL` — Deployed frontend URL

### Frontend (Vercel)
- `REACT_APP_API_URL` — Backend API base URL, if used by the frontend code

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
